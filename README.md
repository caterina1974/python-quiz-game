# 🎯 Python 퀴즈 게임 (Python Quiz Game)

## 1. 프로젝트 소개

Python 기초 문법을 활용하여 제작한 콘솔 기반 퀴즈 게임입니다.

사용자는 퀴즈를 풀고, 새로운 문제를 추가하고, 등록된 문제와 최고 점수를 확인할 수 있습니다.

게임 데이터는 JSON 파일로 저장하며, 백업 및 복구 기능을 통해 데이터 손상에 대비하도록 구현했습니다.

- **개발 환경:** Windows 11
- **개발 언어:** Python
- **데이터 저장:** JSON
- **버전 관리:** Git / GitHub
- **자동 테스트:** GitHub Actions
- **테스트 프레임워크:** Python unittest

## 2. 주요 기능

| 기능 | 설명 |
|---|---|
| 퀴즈 풀기 | 등록된 문제를 순서대로 풀고 점수를 계산합니다. |
| 퀴즈 추가 | 문제, 선택지 4개, 정답 번호를 입력하여 문제를 추가합니다. |
| 퀴즈 목록 | 등록된 문제와 선택지를 확인합니다. |
| 점수 확인 | 최고 점수와 정답 개수를 확인합니다. |
| 데이터 저장 | 퀴즈와 점수 정보를 JSON 파일에 저장합니다. |
| 데이터 백업 | 저장하기 전에 기존의 정상 데이터를 백업합니다. |
| 데이터 복구 | 저장 파일이 손상되었을 때 백업 파일로 복구할 수 있습니다. |
| 데이터 초기화 | 복구할 수 있는 백업이 없을 때 기본 퀴즈로 초기화할 수 있습니다. |

## 3. 실행 방법

### 3-1. Python 설치 확인

Windows PowerShell에서 다음 명령어를 실행합니다.

```powershell
py --version
```

Python 버전이 표시되면 설치가 확인된 것입니다.

### 3-2. 프로젝트 실행

프로젝트 폴더에서 PowerShell을 열고 다음 명령어를 실행합니다.

```powershell
py -X utf8 main.py
```

### 3-3. 메뉴 구성

```text
================================================
             🎯 나만의 퀴즈 게임 🎯
================================================
1. 퀴즈 풀기
2. 퀴즈 추가
3. 퀴즈 목록
4. 점수 확인
5. 종료
================================================
```

메뉴 번호를 입력하여 원하는 기능을 실행할 수 있습니다.

## 5. 데이터 저장 및 백업·복구

### 5-1. JSON 데이터 저장

게임 데이터는 `state.json`에 JSON 형식으로 저장합니다.

저장 항목은 다음과 같습니다.

- `quizzes`: 퀴즈 문제, 선택지, 정답
- `best_score`: 최고 점수
- `best_correct`: 최고 기록의 정답 개수
- `best_total`: 최고 기록 당시 전체 문제 수
- `has_played`: 게임 플레이 여부

### 5-2. 백업 기능

새로운 데이터를 저장하기 전에 기존 `state.json`의 데이터가 정상인지 먼저 검사합니다.

기존 데이터가 정상이라면 해당 내용을 `state.backup.json`에 백업한 다음 새로운 데이터를 저장합니다.

기존 파일이 손상된 경우에는 정상적인 백업 파일을 손상된 데이터로 덮어쓰지 않도록 처리했습니다.

### 5-3. 원자적 파일 저장

데이터를 바로 기존 파일에 덮어쓰지 않고 임시 파일인 `.tmp` 파일에 먼저 기록합니다.

기록이 완료되면 `os.replace()`를 사용하여 최종 파일로 교체합니다.

이를 통해 저장 도중 프로그램이 중단되더라도 기존 데이터가 불완전하게 변경될 위험을 줄였습니다.

### 5-4. 데이터 복구 및 초기화

`state.json`을 찾을 수 없거나 읽을 수 없는 경우 백업 파일을 확인합니다.

사용자는 다음 중 하나를 선택할 수 있습니다.

1. 백업 파일에서 데이터 복구
2. 기본 퀴즈 데이터로 초기화
3. 아무것도 변경하지 않고 종료

사용 가능한 백업 파일이 없는 경우에도 초기화 또는 종료를 선택할 수 있습니다.

복구를 취소하거나 종료하는 경우에는 기존 파일을 임의로 덮어쓰지 않도록 처리했습니다.

## 7. 테스트 및 검증

Python의 `unittest`를 이용하여 기능별 테스트를 작성했습니다.

### 7-1. 테스트 구성

| 테스트 파일 | 테스트 내용 | 테스트 수 |
|---|---|---:|
| `tests/test_quiz.py` | 퀴즈 생성, 입력값 검증, 정답 판정 등 | 9개 |
| `tests/test_storage.py` | 최초 실행, 백업, 복구, 초기화, 저장 및 임시 파일 정리 | 6개 |
| **합계** | | **15개** |

### 7-2. 테스트 실행 방법

프로젝트 폴더에서 다음 명령어를 실행합니다.

```powershell
py -X utf8 -m unittest discover -s tests -v
```

모든 테스트가 정상적으로 통과하면 `OK`가 표시됩니다.

### 7-3. GitHub Actions 자동 테스트

`.github/workflows/python-tests.yml`을 이용하여 GitHub에 코드가 반영되면 자동으로 테스트를 실행하도록 구성했습니다.

- Python 3.10
- Python 3.11
- `unittest` 자동 실행
- 테스트 결과 확인

GitHub Actions 실행 결과에서 **completed successfully**가 표시되면 해당 실행의 테스트가 성공한 것입니다.
