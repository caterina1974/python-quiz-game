# 나만의 파이썬 기초 퀴즈 게임

Python 기초 문법을 객관식 퀴즈로 복습하고, 사용자가 추가한 문제와 최고 점수를 JSON 파일에 저장하는 Windows 콘솔 프로그램입니다.

| 항목 | 내용 |
|---|---|
| GitHub 저장소 | https://github.com/caterina1974/python-quiz-game |
| 개발 환경 | Windows 11 |
| Python | 3.10 이상 |
| 외부 패키지 | 없음 (Python 표준 라이브러리 사용) |
| 자동 테스트 | `unittest` 15개 |
| CI | GitHub Actions에서 Python 3.10, 3.11 테스트 |

## 1. 프로젝트 소개

이 프로젝트는 Python 입문자가 기본 문법을 직접 문제로 풀면서 복습할 수 있도록 만든 콘솔 퀴즈 게임입니다. 기본 퀴즈 7개가 제공되며, 사용자가 새로운 문제를 추가할 수도 있습니다.

프로그램은 `Quiz`와 `QuizGame` 클래스를 사용하는 객체 지향 구조로 작성했습니다. 퀴즈와 최고 점수는 프로젝트 폴더의 `state.json`에 저장하므로 프로그램을 종료한 뒤 다시 실행해도 데이터를 이어서 사용할 수 있습니다.

## 2. 퀴즈 주제와 학습 범위

퀴즈는 개발 입문 단계에서 자주 사용하는 Python 기초 문법을 중심으로 구성했습니다.

- 화면 출력 함수와 입력
- 문자열, 정수, 불리언 등 기본 자료형
- 형 변환 함수
- 조건문과 반복문
- 리스트와 딕셔너리

문법을 읽는 데서 그치지 않고 직접 정답을 선택해 보도록 4지선다형으로 구성했습니다.

## 3. 주요 기능

| 기능 | 설명 |
|---|---|
| 퀴즈 풀기 | 등록된 문제를 순서대로 출제하고 정답 여부와 최종 점수를 표시합니다. |
| 퀴즈 추가 | 문제, 선택지 4개, 정답 번호(1~4)를 입력해 새 문제를 등록합니다. |
| 퀴즈 목록 | 저장된 전체 문제와 선택지를 확인합니다. |
| 최고 점수 확인 | 최고 점수와 해당 기록의 정답 수를 표시합니다. |
| 자동 저장 | 퀴즈 추가 및 게임 결과를 `state.json`에 저장합니다. |
| 입력값 검사 | 빈 입력, 숫자가 아닌 입력, 허용 범위를 벗어난 숫자를 다시 입력하도록 안내합니다. |
| JSON 데이터 검증 | 파일을 읽을 때 퀴즈와 점수 데이터의 구조 및 값이 유효한지 검사합니다. |
| 자동 백업 | 저장하기 전에 기존 `state.json`이 유효한지 확인하고, 유효하면 `state.backup.json`으로 백업합니다. |
| 데이터 복구 | 저장 파일이 없거나 손상된 경우 백업 복구, 기본 데이터 초기화 또는 종료를 선택할 수 있습니다. |
| 안전한 파일 저장 | 임시 파일에 먼저 기록한 뒤 `os.replace()`로 교체해 저장 도중 파일이 불완전해질 위험을 줄입니다. |
| 안전한 종료 | `Ctrl+C` 또는 입력 종료(`EOFError`)가 발생하면 저장을 시도하고 종료합니다. |

## 4. 개발 환경 및 실행 방법

### 필요한 환경

- Windows 11
- Python 3.10 이상
- Visual Studio Code (선택 사항)
- Git (소스 코드 버전 관리 및 GitHub 사용 시 필요)

별도의 Python 패키지는 설치하지 않아도 됩니다.

### 실행하기

1. GitHub 저장소를 ZIP으로 내려받거나 Git으로 복제합니다.
2. 압축을 풀었다면 `main.py`가 있는 프로젝트 폴더를 엽니다.
3. PowerShell 또는 Windows 터미널에서 해당 폴더로 이동합니다.
4. 다음 명령어를 실행합니다.

```powershell
py -X utf8 main.py
```

`-X utf8` 옵션은 Windows 터미널에서 한글 입출력을 UTF-8로 처리하는 데 도움을 줍니다.

### 프로그램 메뉴

```text
1. 퀴즈 풀기
2. 퀴즈 추가
3. 퀴즈 목록
4. 점수 확인
5. 종료
```

메뉴에 표시된 번호를 입력하고 Enter를 누르면 해당 기능이 실행됩니다.

## 6. 클래스 및 주요 메서드

### `Quiz`

퀴즈 한 문제를 표현하는 클래스입니다.

| 메서드 | 역할 |
|---|---|
| `__init__()` | 문제 내용, 선택지 4개, 정답 번호를 검사하고 객체를 생성합니다. |
| `display()` | 문제와 선택지를 화면에 표시합니다. |
| `is_correct()` | 사용자가 입력한 답이 정답인지 확인합니다. |
| `to_dict()` | 퀴즈 객체를 JSON 저장에 사용할 수 있는 딕셔너리 형태로 변환합니다. |
| `from_dict()` | 딕셔너리 데이터를 검사해 `Quiz` 객체로 복원합니다. |

### `QuizGame`

게임 메뉴, 문제 목록, 점수와 데이터 파일을 관리하는 클래스입니다.

| 메서드 | 역할 |
|---|---|
| `__init__()` | 저장 파일과 백업 파일 경로 및 게임 상태를 초기화합니다. |
| `make_default_quizzes()` | 기본 퀴즈 7개를 생성합니다. |
| `read_non_empty()` | 빈 문자열이 입력되지 않도록 검사합니다. |
| `read_number()` | 지정된 범위의 정수가 입력될 때까지 다시 요청합니다. |
| `_read_state_file()` | JSON 파일을 읽고 퀴즈 및 점수 데이터의 유효성을 검사합니다. |
| `_apply_state()` | 검증된 데이터를 현재 게임 상태에 반영합니다. |
| `_reset_to_defaults()` | 퀴즈와 점수를 기본 상태로 초기화합니다. |
| `load_data()` | 저장 데이터를 불러오고, 문제가 있으면 백업 복구·초기화·종료 선택을 제공합니다. |
| `_atomic_write_text()` | 임시 파일에 쓴 뒤 대상 파일을 안전하게 교체합니다. |
| `save_data()` | 기존 유효 데이터 백업 후 현재 데이터를 저장합니다. |
| `show_menu()` | 메인 메뉴를 표시합니다. |
| `play_quiz()` | 퀴즈를 진행하고 점수를 계산·저장합니다. |
| `add_quiz()` | 새 퀴즈를 입력받아 목록에 추가합니다. |
| `show_quizzes()` | 등록된 퀴즈 목록을 표시합니다. |
| `show_score()` | 최고 점수를 표시합니다. |
| `run()` | 메뉴 선택에 따라 게임 기능을 실행합니다. |

## 7. 데이터 저장 및 복구 방식

### 저장 데이터: `state.json`

`state.json`은 `main.py`와 같은 프로젝트 폴더에 생성되는 UTF-8 JSON 파일입니다.

| 키 | 설명 |
|---|---|
| `quizzes` | 퀴즈 목록. 각 문제는 `question`, `choices`, `answer`를 가집니다. |
| `best_score` | 최고 점수(0~100) |
| `best_correct` | 최고 기록에서 맞힌 문제 수 |
| `best_total` | 최고 기록에서 푼 전체 문제 수 |
| `has_played` | 퀴즈를 한 번이라도 진행했는지 나타내는 값 |

데이터 구조 예시는 다음과 같습니다.

```json
{
  "quizzes": [
    {
      "question": "Python에서 화면에 글자를 출력할 때 사용하는 함수는?",
      "choices": ["input()", "print()", "len()", "type()"],
      "answer": 2
    }
  ],
  "best_score": 71,
  "best_correct": 5,
  "best_total": 7,
  "has_played": true
}
```

위 내용은 데이터 구조를 설명하기 위한 예시이며, 실제 저장 파일에는 사용자가 추가한 퀴즈와 실제 점수가 기록됩니다.

### 백업 및 복구 절차

1. 프로그램은 먼저 `state.json`을 읽고 JSON 형식과 데이터 구조를 검사합니다.
2. 저장 파일이 없거나 손상된 경우 `state.backup.json`이 있는지 확인합니다.
3. 사용할 수 있는 백업이 있으면 다음 중 하나를 선택합니다.
   - `1`: 백업 파일의 데이터로 복구
   - `2`: 기본 퀴즈와 점수로 초기화
   - `3`: 파일을 변경하지 않고 종료
4. 사용할 수 있는 백업이 없으면 기본 데이터로 초기화하거나 파일을 변경하지 않고 종료할 수 있습니다.
5. 저장할 때 기존 `state.json`이 유효한 경우에만 이전 내용을 백업합니다. 기존 파일이 손상된 경우에는 그 내용을 정상 백업 위에 덮어쓰지 않습니다.

### 임시 파일을 이용한 안전한 저장

저장할 내용을 바로 `state.json`에 덮어쓰지 않습니다. 먼저 `state.json.tmp`에 기록하고 파일 내용을 디스크에 반영한 다음 `os.replace()`로 실제 파일을 교체합니다. 백업 파일을 만들 때도 같은 방식을 사용합니다. 저장 과정에서 남은 임시 파일은 정리합니다.

## 8. 자동 테스트

Python 표준 라이브러리 `unittest`를 사용합니다. 별도 패키지 설치는 필요하지 않습니다.

### Windows에서 테스트 실행

프로젝트 최상위 폴더에서 PowerShell을 열고 실행합니다.

```powershell
py -X utf8 -m unittest discover -s tests -v
```

### 테스트 구성

| 테스트 파일 | 테스트 수 | 확인 내용 |
|---|---:|---|
| `tests/test_quiz.py` | 9개 | 문제·선택지 저장, 정답·오답 판정, 딕셔너리 변환 및 복원, 잘못된 정답·선택지 수·빈 문제 거부 |
| `tests/test_storage.py` | 6개 | 최초 실행 파일 생성, 이전 데이터 백업, 손상 파일의 백업 복구, 기본값 초기화, 손상 파일을 보존한 종료, 임시 파일 정리 |
| **합계** | **15개** | 퀴즈 기능과 저장·복구 기능 검증 |

### GitHub Actions 자동 테스트

`.github/workflows/python-tests.yml`에 자동 테스트 작업을 설정했습니다.

- `main` 브랜치에 push하면 실행됩니다.
- GitHub Actions 화면에서 수동 실행(`workflow_dispatch`)할 수도 있습니다.
- Python 3.10과 Python 3.11 환경에서 각각 테스트합니다.
- 실행 명령은 `python -m unittest discover -s tests -v`입니다.

## 9. Git 및 GitHub 실습

프로젝트를 개발하고 GitHub에 관리하면서 사용한 주요 Git 명령어입니다.

| 명령어 | 목적 |
|---|---|
| `git init` | 로컬 폴더를 Git 저장소로 초기화 |
| `git add` | 변경 파일을 커밋 대상으로 선택 |
| `git commit` | 변경 이력을 로컬 저장소에 기록 |
| `git push` | 커밋을 GitHub 원격 저장소에 업로드 |
| `git pull` | 원격 저장소의 변경 내용을 로컬에 반영 |
| `git checkout` | 브랜치 전환 또는 브랜치 생성 |
| `git clone` | GitHub 저장소를 새 폴더에 복제 |
| `git log --oneline --graph --decorate --all` | 브랜치와 커밋 이력을 그래프 형태로 확인 |

퀴즈 풀이 안내 문서를 기능 브랜치에서 수정한 뒤 `main` 브랜치에 반영하는 작업과, 저장소 복제 및 원격 변경사항 가져오기 연습을 진행했습니다.
